# Free AI Tools Guide

An interactive guide to free AI tools across 11 categories. Pick your role, search, and open any row to see who can use the tools, typical outputs, and free-tier limits.

Single-file site: no build step, no dependencies.

## Host on GitHub Pages

1. Create a new repository (for example `free-ai-tools-guide`).
2. Upload `index.html` and `README.md` to the repository root.
3. Go to **Settings > Pages**.
4. Under **Build and deployment**, set Source to **Deploy from a branch**, choose `main` and `/ (root)`, then **Save**.
5. After a minute or two the site is live at `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`.

## Updating the content

Open `index.html` and edit the `D` array in the script section. Each entry is: category, example tools, who can use them, outputs, free-tier limits, and the roles it appears for.

## Note

Free-tier limits are general patterns, not exact figures. Check each tool's pricing page before relying on it.
